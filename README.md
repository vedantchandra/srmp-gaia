## Running the notebooks

**GitHub Codespaces** (works on Chromebooks; needs a free GitHub account)

1. Click [**Open in Codespaces**](https://codespaces.new/vedantchandra/srmp-gaia?quickstart=1), then
   **Create codespace**. The first start takes 2–3 minutes.
2. Wait until the setup in the bottom panel finishes, then click a notebook in the file list on
   the left.
3. If it asks you to pick a kernel, choose **Python Environments → Python 3.12**.
4. Run a cell with **Shift + Enter**.

If a notebook shows up as a page of code text (starting with `{ "cells": [`), close that tab,
then right-click the file → **Open With… → Jupyter Notebook**. Your work is saved in the
codespace: next time, open it again from [github.com/codespaces](https://github.com/codespaces).

**Google Colab** (needs a Google account)

Click an "open in Colab" link above. Before you start, click **File → Save a copy in Drive** so
your work is saved.
